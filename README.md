# SQE Library Management

## Project Description

SQE Library Management is a software project designed to manage library activities in an organized and efficient way.

The system helps manage library books, students, book issuing, book returning, and other basic library operations.

The purpose of this project is to apply Software Quality Engineering practices and develop a reliable, maintainable, and user-friendly library management system.

## Project Structure

- src/ - Application source code
- tests/ - Test cases and automated tests
- docs/ - Project documentation
- screenshots/ - Evidence of testing and project activities
